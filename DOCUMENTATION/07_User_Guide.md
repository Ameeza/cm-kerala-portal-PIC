# 07 – User Guide

## Citizen
1. Register or sign in.
2. Select **Submit a grievance**; enter district, category, subject and detailed description.
3. Optionally request AI suggestions and review the labelled recommendations.
4. Attach up to three JPG, PNG or PDF files (5 MB each), then submit.
5. Save the generated `CMK-YYYY-XXXXXX` reference number.
6. Open **Track grievance** or your dashboard to review status history and department assignment.

## CMO administrator
1. Sign in with the CMO demo account.
2. Open Dashboard and inspect totals and district chart.
3. Open a grievance, select the appropriate department and priority, add forwarding remarks and assign.
4. Review officer updates and update status. Resolve only after reviewing the action report.

## Department officer
1. Sign in with the officer account.
2. Review grievances assigned to the officer's department.
3. Open a record, enter investigation remarks/action-taken report and update status.
4. Send the response back for CMO review.
